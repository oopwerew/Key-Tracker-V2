# 🔑 Key Tracker V2 — Десктопная версия (PC / Mac)

Современное десктопное приложение для учета и контроля выдачи ключей по кабинетам.

## 🎨 Дизайн и интерфейс
- **Стиль:** iOS Human Interface Guidelines (чистый белый фон, скругленные углы карточек, сегментированные переключатели).
- **Цветовая палитра:** White & Blue (акцентный синий `#007AFF`, белый `#FFFFFF`, мягкий фон `#F2F2F7`).
- **Шрифт:** Apple SF Pro Display / Helvetica Neue.

---

## 👥 Роли и возможности

### 👤 Режим пользователя
- Быстрый поиск кабинета по номеру или названию.
- Фильтры «Все» / «Свободные».
- Просмотр статуса ключа (В наличии / На руках).
- Взятие ключа с фиксацией ФИО и времени.
- Возврат взятого ключа.

### 🛡 Режим администратора
- Сводная статистика (Всего кабинетов, Свободно, Выдано).
- Выдача ключей сотрудникам напрямую.
- Прием возврата ключей.
- Добавление новых кабинетов (номер, название, этаж, примечания).
- Удаление кабинетов.
- **Журнал операций** — полная история всех взятий и возвратов с датой и временем.

---

## 🚀 Запуск приложения

1. Установите зависимости:
   ```bash
   pip3 install -r requirements.txt
   ```

2. Запустите приложение:
   ```bash
   python3 app.py
   ```
