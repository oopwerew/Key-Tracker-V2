# 🔑 Key Tracker V2 — Система учета и выдачи ключей

Совместный кроссплатформенный проект для администратора ресепшена, управляющего выдачей и возвратом ключей от помещений и кабинетов.

## 🏗 Архитектура проекта

Проект разделен на три независимых модуля с единой базой данных:

```
Key-Tracker-V2/
├── server/       # 🚀 Бэкенд REST API (FastAPI + SQLite WAL)
├── mobile/       # 📱 Мобильное приложение (Python + Flet, стиль iOS Cupertino)
└── desktop/      # 💻 Десктопное приложение (CustomTkinter, ветка desktop-version)
```

## 🚀 Быстрый запуск

### 1. Установка зависимостей

Рекомендуется использовать общее виртуальное окружение:

```bash
# Создание venv
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей сервера и мобилки
pip install -r server/requirements.txt
pip install -r mobile/requirements.txt
```

---

### 2. Запуск сервера (REST API)

Сервер поднимается на порту `8000` и слушает `0.0.0.0`, что позволяет подключаться клиентам из локальной сети:

```bash
./server/run_server.sh
# или
uvicorn server.main:app --host 0.0.0.0 --port 8000 --reload
```

- Документация Swagger UI доступна по адресу: `http://localhost:8000/docs`
- Проверка здоровья: `http://localhost:8000/health`

---

### 3. Запуск мобильного приложения

```bash
./mobile/run_mobile.sh
# или
python3 mobile/main.py
```

*Приложение откроется в мобильном разрешении. Если сервер запущен на другом компьютере, перейдите на вкладку «Сервер» и укажите локальный IP (например: `http://192.168.1.50:8000`).*

---

### 4. Запуск десктопной версии

```bash
./desktop/run.sh
# или
python3 desktop/app.py
```

---

## 📡 REST API эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/keys` | Список ключей (фильтры `search`, `filter_type`) |
| `GET` | `/keys/{id}` | Информация о конкретном ключе |
| `POST` | `/keys/{id}/issue` | Выдача ключа человеку (ФИО, телефон, срок) |
| `POST` | `/keys/{id}/return` | Прием возврата ключа |
| `GET` | `/history` | Журнал истории выдач и возвратов |
| `GET` | `/stats` | Счетчики (Всего, В наличии, Выдано) |
| `POST` | `/keys` | Добавление нового кабинета |
| `DELETE` | `/keys/{id}` | Удаление кабинета |
