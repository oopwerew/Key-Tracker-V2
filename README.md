# 🔑 Key Tracker V2 — Единая экосистема (Web + Mobile + Desktop)

Полноценная система учёта и контроля выдачи ключей по кабинетам с **мгновенной синхронизацией** между всеми устройствами.

---

## 🏗 Архитектура системы

```
                 ┌────────────────────────────────────────┐
                 │    Единый Сервер (FastAPI + SQLite)    │
                 │         Порт: 8080 / 0.0.0.0           │
                 └───────────────────┬────────────────────┘
                                     │
             ┌───────────────────────┼───────────────────────┐
             │                       │                       │
             ▼                       ▼                       ▼
      [Веб-версия]           [Мобилка на Flet]       [ПК-версия GUI]
    (Браузер на ПК)         (Телефон или Окно)       (CustomTkinter)
```

1. **Единый Бэкенд (`server.py` + `database.py`):**
   * Единая база данных SQLite (`data/keys.db`).
   * REST API с поддержкой CORS для локальной сети и веб-клиентов.
   * Система безопасности: роли (Администратор / Пользователь), хэширование паролей (`bcrypt`), JWT-сессии, инвайт-код для админов (`ADMIN_INVITE_CODE`).
2. **Веб-версия (`/static`):**
   * Премиальный дизайн iOS White & Blue (Inter, Lucide SVG, без эмодзи, `max-width: 1120px`).
   * Доступна в браузере по адресу `http://localhost:8080`.
3. **Мобильное приложение (`/mobile`):**
   * Разработано на **Flet** (движок Flutter на чистом Python).
   * Нативный стиль Cupertino (iOS), плавная работа, вкладка «Сервер» для настройки IP-адреса.

---

## 🚀 Как запустить и протестировать синхронизацию

### Шаг 1. Запуск сервера (Сердце системы)

В основном терминале:
```bash
./run.sh
```
*(Или `python3 server.py`)*.  
Сервер запустится на `http://localhost:8080` и автоматически откроет веб-интерфейс в браузере!

* **Вход для Администратора:** `admin` / `admin123`
* **Вход для Пользователя:** `user` / `user123`

---

### Шаг 2. Запуск мобильного приложения

Во втором окне терминала выполните:
```bash
cd mobile
./run_mobile.sh
```
*(Или `python3 main.py`)*.  
Откроется аккуратное окно мобильного приложения в размерах экрана iPhone.

---

### 🔄 Как проверить синхронизацию:

1. Откройте рядом два окна: браузер (`http://localhost:8080`) и окно мобильного приложения.
2. В мобильном приложении нажмите на свободный кабинет (например, **№101**) и нажмите **«Выдать ключ»** (введите имя и телефон).
3. В браузере на ПК обновите список — статус кабинета **№101 мгновенно сменится на «На руках»**, отобразится имя и телефон сотрудника!
4. Нажмите в веб-интерфейсе **«Принять возврат»** — в мобильном приложении ключ сразу станет **«В наличии»**!

---

### 📱 Подключение с реального смартфона по Wi-Fi:

1. Убедитесь, что ваш компьютер и смартфон подключены к одной Wi-Fi сети.
2. Локальный IP вашего Mac: **`192.168.1.64`** (или проверьте командой `ipconfig getifaddr en0`).
3. В мобильном приложении перейдите на вкладку **«Сервер»** и введите:
   ```text
   http://192.168.1.64:8080
   ```
4. Нажмите **«Проверить подключение»** — связь установлена, все операции на телефоне синхронизируются с компьютером в реальном времени!
